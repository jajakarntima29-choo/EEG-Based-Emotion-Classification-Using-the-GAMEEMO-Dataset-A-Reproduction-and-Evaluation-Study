# EEG-Based Emotion Classification
## Using Machine Learning and the GAMEEMO Dataset

Exploring the possibility of recognizing human emotions
through EEG signals using machine learning techniques.

---

## About This Project

This project focuses on emotion classification
using Electroencephalography (EEG) signals.

We explore EEG signal processing, feature extraction,
and machine learning models to investigate how
brain activity can be used for emotion recognition.

## Project Overview

- Dataset: GAMEEMO
- EEG Channels: 14
- Original Participants: 28
- Selected Participants: 18
- Sampling Rate: 128 Hz
- Feature Extraction: DWT (db2)
- Models: SVM, kNN, MLPNN
- Evaluation: 3-Fold Cross-Validation
